# Open-source distribution

NPZSee is published as an independently named derivative of
[LiukDiihMieu/npyquick](https://github.com/LiukDiihMieu/npyquick), with clear credit
in README and NOTICE and the original GPL v3-or-later license retained.

The repository includes source, build scripts, Cargo.lock, localization resources,
font assets and third-party copyright/license notices. Binary archives retain
those notices. A matching corresponding-source archive includes locked Rust
dependency sources; platform SDKs, compilers and user data are excluded.

Font files are unmodified upstream Noto fonts under the SIL Open Font License.
Their original notices are retained in LICENSES/fonts/. The software does not
reuse the upstream project's logo. Low-level parser/system diagnostic details
use English; interface text is available in all six UN languages.

Actual releases and validation status are recorded in release-status.md. PyPI
account configuration and, if desired later, platform signing identities belong
to the account holder and are not embedded in source code.
