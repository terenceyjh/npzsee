# NPZSee 0.1.0

A native viewer for multidimensional `.npy` and `.npz` arrays, written in Rust.

- Navigate arrays by dimension, inspect exact table values and expandable JSON.
- Click a cell or JSON value to read/copy its full content in the docked detail pane.
- Plot curves and filled histograms, with zoom/pan, complex and X/Y modes, and SVG export.
- Choose English, 简体中文, Français, Español, Русский or العربية in the toolbar.

## Downloads

Standalone programs do not need Python or Rust. Extract the complete archive:

| System | CPU | Asset |
| --- | --- | --- |
| Windows | x86_64 | NPZSee-0.1.0-windows-x86_64.zip |
| Windows | ARM64 | NPZSee-0.1.0-windows-arm64.zip |
| Linux | x86_64 | NPZSee-0.1.0-linux-x86_64.tar.gz |
| Linux | ARM64 | NPZSee-0.1.0-linux-arm64.tar.gz |
| macOS 13+ | Intel | NPZSee-0.1.0-macos-x86_64.tar.gz |
| macOS 13+ | Apple Silicon | NPZSee-0.1.0-macos-arm64.tar.gz |

Windows: run `npzsee.exe`. macOS: open `NPZSee.app`. Linux: run `./npzsee` in a graphical desktop session.
Linux needs glibc 2.28+ and its X11/Wayland/OpenGL runtime libraries; see the repository's platform notes.
Binaries are currently unsigned; the macOS app is not Developer ID notarized.

The matching pip wheels are attached as well. Python 3.10+ is required to install a wheel:

```sh
python -m pip install ./npzsee-0.1.0-py3-none-<your-platform>.whl
npzsee
```

PyPI publication is pending account-holder setup. `pip install npzsee` is not available until that step completes.

## Verification and source

The release build checks all six native OS/CPU combinations, 31 Rust tests and 24 independent NumPy compatibility cases on each, plus actual pip installations. Linux x86_64/ARM64 and local Windows render real GUI frames in all six languages, including multidimensional navigation, plot, histogram and long-cell inspection. macOS interactive file dialogs/clipboard still benefit from additional real-device use; the user reported basic operation of the earlier Mac ARM build.

Build: https://github.com/terenceyjh/npzsee/actions/runs/40091597920
Source commit: 063512d22c3a63a177fa536c8300bbf4ee6b8b91

`npzsee-0.1.0-corresponding-source.tar.gz` contains matching sources and locked Rust dependency sources. Verify downloads using `SHA256SUMS`. The regular source distribution is attached for standard pip builds.
